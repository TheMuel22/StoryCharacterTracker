# Story Writing App

A mobile-friendly web application for creative writing with Character Tracker integration.

## Features

- 📱 **Mobile-responsive design** - Works perfectly on phones and tablets
- 📚 **Chapter management** - Organize your story into chapters
- ✏️ **Rich writing interface** - Distraction-free writing experience
- 🔍 **Spell checking** - Built-in spell check functionality
- 📝 **Thesaurus integration** - Find synonyms with Datamuse API
- 👥 **Character integration** - Connect to Character Tracker app
- 🌙 **Dark mode** - Eye-friendly writing in low light
- 💾 **Auto-save** - Never lose your work
- 📊 **Word counting** - Track your progress

## Character Tracker Integration

This app can connect to your Character Tracker server to:
- Display your characters while writing
- Insert character names with a click
- Keep character details accessible during writing

## Technologies Used

- HTML5, CSS3, JavaScript (ES6+)

- Local storage for data persistence
- Responsive CSS Grid and Flexbox
- Inter font family for clean typography

## Character Tracker Connection

To connect to your Character Tracker:
1. Make sure your Character Tracker server is running
2. Click "Connect Tracker" in the Characters section
3. Enter your server URL (e.g., `http://192.168.4.145:8080`)
4. Your characters will appear for easy reference while writing
