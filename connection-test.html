📖 How to Connect

Step 1: Start your Character Tracker desktop application
Step 2: Click "Export PDF" button to start the server
Step 3: Copy the server URL from the popup (should be automatically copied to clipboard)
Step 4: Paste the URL in the input field above and click "Connect"
Step 5: Once connected, go to your main web app to start writing with character integration!
